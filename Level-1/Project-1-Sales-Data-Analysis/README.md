# Sales Data Analysis

## Cognetix Technology — Data Analyst Internship

This project analyzes sales transaction data using Python, Pandas, Matplotlib, and Seaborn to identify important business trends and performance patterns.

## Objective

The objective of this project is to analyze sales data and generate actionable insights related to:

- Overall sales performance
- Product-line performance
- Geographic performance
- Top-performing products
- Monthly and yearly sales trends
- Deal-size distribution
- Order-status performance

## Dataset

The project uses the Sample Sales Data dataset containing **2,823 sales records and 25 attributes**.

The dataset includes information such as:

- Order number
- Quantity ordered
- Price
- Sales
- Order date
- Product line
- Product code
- Customer
- Country
- Deal size
- Order status

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
