# Project 3 - Interactive Sales Dashboard

## Objective

The objective of this project is to analyze the US Superstore dataset and develop an interactive dashboard for monitoring sales performance across regions, product categories, and time periods.

## Dataset

The project uses the US Superstore dataset provided in Excel format.

The dataset contains information related to:

- Orders
- Customers
- Products
- Regions
- Categories
- Sales
- Quantity
- Discount
- Profit
- Order and shipping dates

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Dash
- Excel
